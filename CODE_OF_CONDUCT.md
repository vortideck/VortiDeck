# Code of Conduct

VortiDeck follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussions about the work, and do not harass anyone. Maintainers may remove comments, issues or contributors that break these rules.

Report problems to conduct@vortideck.com. Reports are handled confidentially.
