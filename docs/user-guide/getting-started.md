# 🚀 Getting Started with VortiDeck

Welcome to VortiDeck! This guide will help you get up and running with the AI-powered control deck and flow builder.

## 📋 Prerequisites

- **Operating System**: Windows 10/11, macOS 10.15+, or Linux
- **Memory**: 4GB RAM minimum, 8GB recommended
- **Storage**: 500MB free space
- **Internet**: Required for AI model access and tool integrations

## 🔧 Installation

### Desktop Application (Recommended)

1. **Download** the latest release from the GitHub releases page
2. **Install** the application for your operating system:
   - **Windows**: Run the `.msi` installer
   - **macOS**: Open the `.dmg` file and drag to Applications
   - **Linux**: Use the `.AppImage` or `.deb` package

3. **Launch** VortiDeck from your applications menu

### Web Application

1. **Visit** the VortiDeck web app at [app.vortideck.com](https://app.vortideck.com)
2. **Sign up** for a free account or log in
3. **Start building** flows immediately in your browser

## 🎯 First Steps

### 1. Explore the Interface

- **Flow Builder**: The main canvas where you create AI workflows
- **Node Library**: Drag-and-drop components on the left sidebar
- **Settings**: Configure AI models and preferences
- **Execute Button**: Run your completed flows

### 2. Create Your First Flow

1. **Add a Trigger**: Drag a "Button Trigger" from the Node Library
2. **Add an AI Node**: Drag "AI Agent (Free)" to the canvas
3. **Connect Them**: Click and drag from the trigger's output to the AI node's input
4. **Configure the AI**: Click the AI node and enter a prompt like "Say hello!"
5. **Execute**: Click the "Execute Flow" button to run your workflow

### 3. Explore AI Behaviors

VortiDeck offers different AI behaviors for various use cases:

- **🤖 FreeAgent**: Autonomous AI with full tool access
- **🧠 Orchestrator**: AI that coordinates multiple tools and workflows  
- **📝 TextOnly**: Simple text generation without tool access

### 4. Add Tools and Integrations

- **System Tools**: File operations, calculations, date/time
- **Audio Tools**: Play sounds, control volume, text-to-speech
- **Integration Tools**: Google Search, weather, translations
- **Custom Tools**: MCP (Model Control Protocol) extensions
